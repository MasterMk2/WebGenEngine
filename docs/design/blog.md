# ブログ v0（2026-11-23）

- 状態: 試作。前段のアプリの後ろ（server.md §6）で、記事を書いて公開する最小の形
- 実装: `packages/server/Blog.php`・`Api.php`（一覧・題名と日付・画像）、`packages/editor/posts.html`・`posts.mjs`・`posts-core.mjs`、`editor.mjs`（記事の切り替え・題名と日付・画像を選ぶ）

## 1. 何ができるか

- 記事の一覧（`posts.html`）で、題名と日付を入れて新しい記事を書き始める。一覧から記事を開いて直す
- エディタの上の欄で、記事の題名と日付を直す。公開中の記事なら、公開中のページの題名と目次もすぐ直る
- 画像の部品で「画像を選ぶ…」を押すと、画像を送って入れる。写真は送る前に長い辺 1600px の JPEG にする（1MB 以下の PNG と GIF はそのまま）
- 公開・公開の取り消し・題名や日付の変更のたびに、ブログの目次（`index.html`）とフィード（`feed.xml`、RSS 2.0）を作り直す
- 記事の一覧で、下書きの記事を「削除」する。消した記事は一覧の下の「削除した記事」に移り、「元に戻す」で下書きとして戻る（2026-11-24）

## 2. 決めたこと

- **ブログは設定で入れる。** `WGE_BLOG_TITLE` があるときだけブログになる。このとき `top` は目次（サーバーが作るページ）で、編集できない（`/api/pages/top/*` は 404）。エディタを `top` で開くと記事の一覧へ移る
- **記事の id は日付と 4 桁の 16 進数**（`20261123-a3f9`）。URL は `<サイト>/<id>/`
- **題名と日付は `page_meta` に持つ。** 保存の規則（`PageStore`・`fixtures/store.json`）には手を入れない。題名は 1 行で 1〜120 文字、日付は実在する `YYYY-MM-DD`
- **目次はソース形式で書いて、ほかのページと同じ書き出しを通す。** 見た目が記事と揃い、属性とクラスの検査（R4）もそのまま効く。題名の `& < > "` は文字参照にする
- **画像は中身のバイトで種類を見分ける**（JPEG・PNG・GIF・WebP）。SVG はスクリプトを含められるので受け付けない。名前は中身の SHA-256 の先頭 16 桁で、同じ画像は 1 つだけ置く。2.5MB まで。`media/` に置き、記事からは `../media/<名前>` で指す（記事は 1 段下のフォルダにあるため）。エディタのプレビューも 1 段下（`/editor/`）にあるので、同じ書き方で見える（前段の入口は `/media/` を配る）
- **フィードの日付は日本時間の 0 時。** `WGE_SITE_URL` が無いと、フィードは作らない
- **削除できるのは公開していない記事だけ。** 公開中の記事は、先にエディタで公開を取り消す。こうすると、削除でサイトが変わることはない。公開中かどうかの確かめと削除の書き込みは同じ書き込みの鍵の中で行うので、あいだに公開が入ることもない
- **削除は「一覧から外す」だけで、中身は消さない。** 下書き・版・題名と日付は残し、`deleted_pages` に id と時刻を足す。消した記事は元に戻すまで、どの操作にも 404 `deleted` を返す（読み込み直しで作り直されることもない）。画像（`media/`）は他の記事と共有しうるので消さない。データベースから本当に消す操作は、まだ無い
- **削除の前に確かめを出さない。** 元に戻せるので、代わりに削除のあとで「元に戻す」を出す
- **`top` は削除できない**（409 `top`）。ブログでないサイトでは、エディタが既定で開くページのため。ブログの `top` はもともと 404

## 3. API（server.md §2.1 に足したもの）

| 要求 | 本文 | 成功 | 失敗 |
|---|---|---|---|
| `GET /api/pages` | — | 200。`pages`（id・title・date・published・savedAt。日付の新しい順） | — |
| `POST /api/pages/{id}/load` | `initialSource`、`meta`（任意。`title`・`date`） | 200。`meta` も返す | 422（`invalid-title`・`invalid-date`） |
| `POST /api/pages/{id}/meta` | `title`、`date` | 200 | 404（読み込まれていない）、422 |
| `POST /api/media` | `data`（base64） | 200。`src` | 413 `too-large`、415 `not-image`、400 |
| `GET /api/ping` | — | ブログなら `blog: true`・`blogTitle` も返す | — |
| `POST /api/pages/{id}/delete` | `{}` | 200。`deletedAt`（ミリ秒） | 409 `published`（公開中）・`top`、404 `not-loaded`・`deleted` |
| `POST /api/pages/{id}/restore` | `{}` | 200。`draft`・`published`（`load` と同じ形） | 409 `not-deleted`、404 `not-loaded` |
| `GET /api/deleted-pages` | — | 200。`pages`（id・title・date・deletedAt。削除の新しい順） | — |

削除した記事への `load`・`draft`・`publish`・`undo-publish`・`meta`・`delete` と版の読み出しは、404 `deleted` になる。
